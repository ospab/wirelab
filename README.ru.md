# wirelab

Песочница для цензуроустойчивых транспортных протоколов. У каждого прогона
три зоны: клиент, сервер и провод между ними. Провод видит только то, что
видел бы наблюдатель на пути: байты, размеры, тайминги.

[English version](README.md)

Два режима:

- **in-process** (работает сейчас): обе стороны в одном процессе, канал
  между ними симулируется. Для протоколов с sans-io ядром (OSTP).
- **контейнеры** (следующий этап): `client`, `wire` и `server` в трёх
  контейнерах на Alpine, `wire` — настоящий маршрутизатор с `tc netem` и
  записью трафика. Для любого протокола, у которого есть бинарник.

Исходы: `PASS`, `FAIL` или `NO DATA`. Проверка, которая не смогла
измерить, так и говорит; за успех она не выдаётся никогда.

## Запуск

Нужны Rust и checkout `ostp` рядом с этим (`../ostp`).

```
cargo build --release
./target/release/wirelab run scenarios/ostp-clean.toml
```

Каждый прогон пишет `runs/<сценарий>-<сид>/`:

| Файл | Содержимое |
|---|---|
| `records.jsonl` | единая шкала времени по трём зонам |
| `wire.pcapng` | провод, открывается в Wireshark (синтетические заголовки IPv4/UDP) |
| `report.json`, `report.txt` | проверки, метрики, сводка по проводу |

Формат сценария: см. `scenarios/`. Планы: [docs/ROADMAP.ru.md](docs/ROADMAP.ru.md).
