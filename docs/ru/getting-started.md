# Начало работы

[English](../en/getting-started.md) · [Документация](../README.md)

## Что нужно

| | |
|---|---|
| Docker Engine с плагином Compose | На Linux — как есть. На Windows — внутри дистрибутива WSL2: wirelab вызывает `wsl -d <дистрибутив> -e docker`. Дистрибутив по умолчанию `Debian`, другой задаётся через `WIRELAB_WSL_DISTRO`. |
| Rust, stable | Собирает команду `wirelab`. На Windows подходит тулчейн MSVC или GNU (`stable-x86_64-pc-windows-gnu`); компилятор C проекту не нужен. |
| git | Cargo берёт ядро протокола OSTP для симулятора с github.com/ospab/ostp. |
| curl | Рецепты скачивают релизы протоколов. В Windows 10 и новее он есть. |
| Место на диске | Несколько ГБ там, где Docker хранит данные (на Windows — диск, где лежит виртуальный диск WSL), и там, где лежит checkout (захваты, загрузки, прогоны). |

Go не нужен: цензор собирается внутри Docker.

## Сборка

```bash
git clone https://github.com/ospab/wirelab
cd wirelab
cargo build --release
```

Бинарник — `target/release/wirelab` (`wirelab.exe` на Windows). Ниже он называется просто `wirelab`.

## Проверка машины

```bash
wirelab doctor
```

Проверяет Docker и Compose, дистрибутив WSL, netem, пакетные сокеты и WireGuard в ядре, свободное место там, где лежат захваты и данные Docker, и собран ли цензор. На каждую проблему печатает команду, которая её исправит; код выхода 1, если что-то надо исправить до запуска.

## Сборка цензора

```bash
wirelab censor build
```

Собирает `wl-censor` с nDPI внутри контейнера и кладёт в `containers/wire/bin/`. Без него лаборатория работает, но провод маршрутизирует средствами ядра и цензора нет. См. [Цензор](censor.md).

## Первая лаборатория

```bash
wirelab lab up --recipe ostp --set transport=tls
wirelab lab panel
```

`lab up` при первом запуске собирает образы узлов и провода, поднимает контейнеры клиента, провода, сервера и цели и настраивает обе стороны по рецепту. `lab panel` печатает ссылку с одноразовым токеном: в ней консоли клиента и сервера, живой захват, помехи канала и цензор. Выберите **Russia (TSPU)** в разделе Censor и примените, чтобы увидеть, что модель делает с туннелем.

```bash
wirelab lab down
```

останавливает контейнеры; папки и записанные сессии остаются.

## Первый прогон

```bash
wirelab lab test scenarios/lab/smoke.toml
```

Одна клетка, несколько нагрузок, отчёт в `runs/lab-smoke-<время>/report.md`. Как писать свои — в [Прогонах](lab-tests.md).
